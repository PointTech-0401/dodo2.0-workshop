前置作業：API Key 與連線檢查

  • 第一次啟動時填入 OpenAI Key 與天氣 Key。
  • 「測試」只檢查 Key 是否有效；按最下方的按鈕才會儲存。
  • 天氣 Key 可以不填，問天氣時會回覆「還沒設定」。
  • 沒有 OpenAI Key 時，聊天功能停用。
