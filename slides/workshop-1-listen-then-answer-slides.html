為什麼要寫 Prompt

豆豆是住在機器人裡的 AI 孫女，陪長照機構的長者。模型本身不知道這些。

沒有 Prompt

只是一個通用助理

不知道自己是誰、在跟誰講話。可能用英文回答、一次講一長串，口氣像客服。

豆豆的 Prompt 寫了什麼

長者聽得懂的講法

一句不超過 15–20 字。沒聽清楚就說「歹勢，可以再講一次嗎？」。時間講不清楚，先問「早上還是下午？」

還有界線

哪些事不能亂講

醫療、用藥、緊急狀況不自己判斷。今天預設 Prompt 的「邊界與安全」分塊寫的就是這個。

Prompt 決定豆豆是誰、怎麼講。什麼時候換人講、能不能被打斷，Prompt 管不到：這是今天的另外兩件事。

WebRTC：瀏覽器直接跟 OpenAI 通話

視訊通話用的就是 WebRTC：聲音一邊講一邊送，不用等整段錄完。

  1. 1
    瀏覽器寫一份連線說明書（SDP）：要傳聲音，也要開一條傳事件的通道。
  2. 2
    說明書交給本機後端，後端補上 API Key，轉給 OpenAI。
  3. 3
    OpenAI 回一份說明書：好，照這樣連。
  4. 4
    連上之後，聲音和事件直接在瀏覽器和 OpenAI 之間傳，不經後端。

語音 AI 的三件事

講什麼、什麼時候換人講、一次講多長，各自由畫面上不同的地方決定。接下來三張依序講。

B 區 · 回合控制

一次講多長

Prompt 不判斷你是否講完；回合控制不決定回答內容。

三種回合判斷

B 區的設定會直接更新目前的對話。

SEMANTIC VAD

聽你話講完了沒

模型看你已經講出的字，判斷這句完整了沒；不完整就多等一下。適合講話慢、句中會停頓的人。

等待傾向 low：讓你慢慢講
SERVER VAD

聽你安靜多久

聲音大過門檻算開始講，安靜超過設定時間算講完，不管你講到哪。反應快，但停頓時容易搶話。

安靜 800 毫秒
PUSH TO TALK

按住講，放開送出

不需要判斷，適合吵雜的環境。

選語音輸入時先用這個

插話時中斷回答的是回合偵測，不是 Prompt。

一次講多長

控制長度有兩種做法。

做法 A · PROMPT 指引

「一次最多兩個短句」

句子完整，但模型不一定每次照做。

做法 B · 字數上限

長度固定

到上限就停止，句子可能斷在一半。

本專案不設字數上限，長度寫在 Prompt 裡。

「安靜多久算講完」只在使用麥克風時有作用，打字送出不經過這個判斷。

實作一：調整 Prompt

使用「打字輸入／文字輸出」，不需要耳麥。

  1. 1
    確認標題下方顯示「Realtime 已連線」。
  2. 2
    問「你叫什麼？我叫什麼？」，確認名字與稱呼。
  3. 3
    輸入：「我今天第一次自己搭公車去醫院，有點緊張。」
  4. 4
    修改「角色與身分」或「對話方式」，下方完整 Prompt 會同步更新。
  5. 5
    按「套用」，輸入同一句話。
  6. 6
    比較內容、語氣與長度。
  7. 7
    在「對話方式」修改長度規則，再比較一次。
人格版本

三個系統預設＋自訂

溫柔陪伴／神經模式／啦啦隊長替換 5 個分塊與聲線，名字與稱呼保留。改過任何一格就記成「自訂」，換去試預設也不會不見。

注意

兩個常見誤解

完整 System Prompt 只能檢視，要修改請回到分塊；打字回答的快慢與 VAD 無關。

實作二：聲音導演

「系統設定」把輸出改成語音，輸入維持打字，戴上耳機。不用麥克風。

  1. 1
    輸入「講一個 30 秒的睡前故事給我聽。」先聽預設的講法。
  2. 2
    只改「個性與聲音」，換成右邊其中一種演法，按「套用」。
  3. 3
    輸入同一句話，聽語氣、速度、停頓差在哪。
  4. 4
    分塊不動，只換「Dodo 的聲線」，按「套用」（會重新連線），再問同一句。
  5. 5
    演法和聲線自己搭一組，系統會記成「自訂」。
演法範例

貼進「個性與聲音」

悄悄話：用氣音、很小聲，像怕吵醒旁邊的人。
夜市叫賣：大聲、有精神，尾音拉長。
深夜電台 DJ：低沉、慢，每句話中間停一下。
廟口講古：抑揚頓挫，講到關鍵處故意停住。

聲線換的是音色，分塊換的是演法，兩個各管各的。

示範：同一份 Prompt、同一句話。

  1. 1
    在「對話方式」最後加一句「一次最多兩個短句」，按「套用」。

對照

插話中斷

由回合偵測執行，不需要模型配合。長度規則寫在 Prompt 裡，模型不一定每次照做。

需要確定發生的行為寫在程式裡。第二堂的主動規則就是這樣設計。

今天的重點

  • 語音 AI 的三件事分開管：講什麼寫在 Prompt，什麼時候換人講交給回合控制，一次講多長也寫在 Prompt。
  • Key 只留在你電腦上的後端；連線那一次經過後端，之後聲音和文字由瀏覽器直連 OpenAI。
  • 聲線換的是音色，「個性與聲音」分塊換的是演法。
  • Prompt 是拜託，模型不一定每次照做；插話中斷由回合偵測執行，一定會發生。需要確定發生的事寫進程式，第二堂從這裡接下去。
  • 按「下載我的 Dodo」帶走這一堂的成果（my-dodo.json），檔案裡不含 API Key；回家用「匯入」就能接著玩。
參考：OpenAI Realtime 官方文件中的文字輸入、連線時送出 Prompt、工具呼叫與回合判斷。
