WORKSHOP 01 · 讓 DODO 聽完，再回答 02 / 16

Voice Agent 不是「多寫一些 Prompt」就會自然

學生要能分清楚三個層次 —— 每一層在本專案都有一個實際對應的位置。

MODEL INSTRUCTIONS

角色、語氣、回答內容與安全界線

寫在畫面左側 A 區的五個分塊裡。

instructions
TURN DETECTION

何時開始聽、何時判定說完、是否允許插話

由右側 B 區的回合設定決定。

session.audio.input.turn_detection
OUTPUT LENGTH

單次回答多長

寫在「對話方式」分塊裡，不設 API 上限 —— 這是刻意的選擇。

（沒有 max_output_tokens）
Prompt 不負責偵測使用者是否說完；回合控制也不負責決定它說什麼。
