開始前：連接真正的模型

沒填 Key 時聊天會直接停用，不會拿罐頭句子假裝自己是模型。

  • 第一次啟動時，畫面上會分別要你填 OpenAI 的 Key 和天氣的 Key。
  • 每個 Key 旁邊只有一顆「測試」；真正存下來靠畫面最下面那顆按鈕。沒測過的 Key 會在存之前自動測一次。
  • 也可以由講師事先幫每台電腦設好。
  • 天氣 Key 沒填一樣可以上課，只是問天氣時它會明講「還沒設定」。
KEY 去了哪裡

只留在你自己這台電腦上

跟著程式一起活著，程式一關就沒了。不會存進瀏覽器、不會寫進 my-dodo.json、也不會出現在網頁程式裡。關掉設定視窗（× 或 Esc）會丟掉還沒存的東西。
