## 2026 共用專案設計

兩堂課使用同一個瀏覽器客端與同一份 `my-dodo.json`。第一堂完成 persona、System instructions 與 Realtime 回合設定；第二堂在原成果上加入三層記憶、主動規則與安全界線。只參加第二堂者載入 `starter/workshop2-default-dodo.json`。全班以打字輸入／文字輸出完成 Prompt 主線與設定預演，有麥克風耳機者可加做真實 WebRTC 語音驗證。

課堂不安排小組討論、跨同學連線或自由探索；每段採「老師示範 → 學生修改 → 固定情境驗證 → 顯示完成」的節奏。

## 第一場：會聽、會說、會等待——Realtime Voice Agent

  時間：165 分鐘
  核心：dodo 的即時語音、輪流說話、打斷、沉默與高齡語音 UX
  程式門檻：低，使用預先建好的共用客端。學生從右側分別修改 Model instructions 與 Realtime 回合設定，不能把兩者混在一起。

  ### 學習目標

  - 理解文字聊天與語音 Agent 的差異。
  - 認識 STT、TTS、VAD、Realtime API 的角色。
  - 理解 Prompt 不負責判斷使用者「說完了」。
  - 比較 Server VAD、Semantic VAD 與 Push-to-talk。
  - 設計適合長者的語速、語氣、等待與打斷機制。
  - 使用測試情境改善語音 Agent。

  ## 第二場：會記得、會主動，也知道何時不要打擾——Proactive & Memory Agent

  時間：165 分鐘
  核心：dodo 三層記憶、主動關心、反向導師、事件決策與安全界線
  程式門檻：低，學生延續第一堂作品或載入講師 starter，再從共用客端修改規則。

  ### 學習目標

  - 理解 AI 記憶與對話紀錄的差異。
  - 判斷哪些資訊應保存、由誰修改、保存多久。
  - 理解被動 Chatbot 與主動 Agent 的差別。
  - 設計 AI 主動開口的時機、內容與優先順序。
  - 測試 Agent 是否過度打擾、洩漏隱私或做出危險判斷。
